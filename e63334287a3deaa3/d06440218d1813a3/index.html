    Avis miles claims

    Players who say they booked a car through Avis (avismiles.js, from the Online panel). Check the confirmation number with Avis (or ask for the confirmation email), then approve to add the miles or turn it down. Both are signed with the admin key like a merge, so only this page can grant miles; the player sees the result in their Avis miles box. The booking details are sealed to the admin key, so only this page can read them.

      Same person?

      Pairs of accounts that look like one person, best first, with the reasons under each. Names count most (the same name, the same name but for numbers or capitals, a Google name's first name, a typo apart), then the same custom avatar, one account stopping as the other started, and one holding nothing the other doesn't; both playing on the same days counts against. Merge keeps the second name (⇄ swaps which one stays) and shows them as one row on every board, with the hours, counts and miles each account earned added back (time and counts two accounts could share in one browser count once) and the better bests. Names aren't unique, so check before merging; you can undo it from the merged account's details. "Not the same" hides a pair in this browser.

        Read-only. Everything here is what the play-time nodes (rooms/lb-all), the account saves (rooms/sv-saves, size only) and the Online panel's status fields already hold, all readable by any signed-in browser: no messages, nothing else. The one exception is a Google player's email: their game stats carry it sealed to the admin key (only the two admin codes open it, like the chat log), so it shows here, under their name, and a search finds it. Accounts that haven't played signed in since this was added don't have it yet; their details can look it up in the site's sign-in records instead (that needs a Google sign-in with the account the analytics dashboard uses).

        Players

        One row per person: accounts merged into one person (on the Stats tab, or by their owner at a Google sign-in) are folded into the account kept, whose play time, tier and bests include them (tick Show merged accounts to list each one, marked). Type is Google when the node carries stats.js's Google mark, else Anonymous (nodes from before the mark was added count as Anonymous). Tap a row for their games, bests, the last 60 days, whether they're online now and the size of their account save.
