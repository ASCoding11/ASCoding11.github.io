## What it is

2048 (Back Room), the single-player number-sliding puzzle, drawn on one canvas (no libraries). The rules are pure functions at the top of the page script (`slideLine`, `moveBoard`, `spawnTile`, `isOver`); a board is an array of n × n numbers, row by row, with 0 for empty (every rule takes the size from the board's length), and `linesFor(n)` lists each direction's rows or columns starting from the wall being moved toward, which is where joins start (`LINES` is the 4 × 4 set). A move that changes nothing does nothing (no new tile, animation or score). A move made during an animation finishes that animation at once and then runs, so fast keys never lose a move or add an extra tile.
