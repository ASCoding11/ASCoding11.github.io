# Game-dev skills from awesome-gamedev-agent-skills

All 79 skills and the router from https://github.com/gamedev-skills/awesome-gamedev-agent-skills (commit c6ca6c4,
November 2026) are copied unchanged into `.claude/skills/`, under the Apache License 2.0 (`LICENSE` and `NOTICE`
here). They cover Godot, Unity, Unreal, Roblox, Bevy, pygame, LÖVE, Defold, Ebitengine, Phaser, PixiJS and three.js,
cross-engine disciplines (game feel, UI/UX, input, physics, saves, audio, cameras, AI, procedural generation, level
design, shaders, performance, asset creation, dialogue), genre guides, and publishing workflows (Steam, itch.io, game
jams, prototyping, design docs). Most aren't used by this site yet; they are here for later projects.

The general ones often show Godot or Unity examples. Where any of them differ from this repo's rules, `CLAUDE.md` and
this repo's own skills (game-graphics, game-performance, war-game-series) win. To update them, copy the folders from a
newer commit and change the commit above.
