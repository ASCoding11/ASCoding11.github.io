# Game-dev skills from awesome-gamedev-agent-skills

These skill folders in `.claude/skills/` are copied unchanged from
https://github.com/gamedev-skills/awesome-gamedev-agent-skills (commit c6ca6c4, November 2026), under the Apache
License 2.0 (`LICENSE` and `NOTICE` here):

- Disciplines: ai-behavior-trees-utility-ai, audio-design, camera-systems, dialogue-systems, game-ai, game-feel,
  game-ui-ux, input-systems, level-design, performance-optimization, physics-tuning, procedural-gen, save-systems,
  shader-programming
- Genres: card-game, fps-shooter, platformer, puzzle, roguelike, rpg, survival-crafting, tower-defense, visual-novel

Left out: the Godot, Unity, Unreal, Roblox, Bevy, pygame, LÖVE, Defold and Ebitengine skills (engines this site
doesn't use); the three.js, Phaser and PixiJS skills (they target three.js r187 with ES-module imports, and this site
uses the r128 global build with no build step); the Steam, itch.io, game-jam, prototype and docs workflows; the router;
and create-game-assets (AI art generation).

They are general advice and often show Godot or Unity examples. Where they differ from this repo's rules, `CLAUDE.md`
and this repo's own skills (game-graphics, game-performance, war-game-series) win. To update them, copy the same
folders from a newer commit and change the commit above.
