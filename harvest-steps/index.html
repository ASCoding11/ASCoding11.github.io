      Bench tile

      Every number in this workbench rests on one figure: how many joules of electricity a real step makes. A plywood bench tile measures it for about $100 in parts.

      Goal: at least 1.5 J per step at 6 mm of travel. A first build will probably land well under that; finding out by how much is the point.

        Bench tile prototype

        A plywood plate on four springs pushes a rack that spins a stepper motor used as a generator. An Arduino logs the voltage across a known load resistor and adds up the energy of each step.

        Wiring

        Connect both rectifier outputs in parallel across the load resistor. The divider scales up to about 28 V down to the Arduino's 5 V range. Tie the Arduino ground to the rectifier minus.

        Logger sketch

        // Harvest Steps bench logger: energy of each step into a 10-ohm load
const float R_LOAD  = 10.0;   // ohms
const float DIVIDER = 5.7;    // (47k + 10k) / 10k
const float VREF    = 5.0;
const unsigned long DT_US = 500;   // sample at 2 kHz

float joules = 0;
unsigned long quietSince = 0;
int steps = 0;

void setup() { Serial.begin(115200); }

void loop() {
  static unsigned long next = micros();
  while ((long)(micros() - next) < 0) {}
  next += DT_US;

  float v = analogRead(A0) * VREF / 1023.0 * DIVIDER;
  if (v > 0.2) {                        // generator is producing
    joules += v * v / R_LOAD * DT_US * 1e-6;
    quietSince = millis();
  } else if (joules > 0 && millis() - quietSince > 400) {
    steps++;                              // step finished: report it
    Serial.print("step ");  Serial.print(steps);
    Serial.print("  J: ");  Serial.println(joules, 3);
    joules = 0;
  }
}

        Test plan

        1. Weigh three walkers of different builds on a bathroom scale.
        2. Set the end stop to 4 mm with shims. Each walker takes 20 normal steps across the tile; record the joules of each.
        3. Repeat at 6 mm and 8 mm. Put the averages into the Energy physics tab: change the efficiencies until its prediction matches what you measured.
        4. If 6 mm gives under 1 J, try a higher gear ratio or a bigger generator before changing anything else.
        5. Spend one market day with a clicker counting entries and aisle traffic, to check the visitor and steps-per-visitor figures.
